Jenkins Automation Workflow Overview

This web application is configured for external Jenkins automation. The workflow includes:

1
Health Verification: Jenkins queries /health API endpoint to verify app status.
2
Data Backup: Jenkins shell script compresses database/app.db and uploads/ into backups/backup_YYYYMMDD_HHMMSS.tar.gz.
3
Integrity Check: Verification script tests archive integrity using tar -tzf.
4
Retention Policy: Script keeps only the latest N backups, removing older archives.
5
Recovery Verification: Test restores backup to a temporary folder and validates SQLite integrity.
